- The diagnostic report lists the value maps (`valve_map`, `mode_map`, `dhw_mode_map`, `buffer_mode_map`, `hc_mode_map`, `program_map`) with their source, preset or configuration, and names a map placed under `entities` by mistake (#125).
- `valve_map` in the visual editor (#126): with a mapped valve, "Advanced" shows "Valve states for hot water" and "Valve states for heating" as comma-separated raw states, with the current state of the valve as help. Only differences from the preset are written back, and a map written in YAML stays as it is unless the fields are changed. The editor warns when a numeric valve sensor has no map, because 1 is then read as hot water. `valve_map` values are accepted in any case and as `heat`, `hot water` or `hot_water`; an invalid value is named in the error.
